# Where these icons come from

- `mercadopago.svg`, `visa.svg`, `mastercard.svg`, `lightning.svg`, `usdt.svg` (the Tether mark): Simple Icons 16.38.0, licence CC0-1.0. https://simpleicons.org
- `usdc.svg`: cryptocurrency-icons (spothq), licence CC0-1.0. https://github.com/spothq/cryptocurrency-icons
- `bank.svg`, `wallet.svg`: drawn for this page. They are neutral icons, not brand marks.

The CC0 licence covers the icon files. Each mark is still a trademark of its owner.
MODO has no file in either set, so the page shows its name with the neutral wallet icon.
